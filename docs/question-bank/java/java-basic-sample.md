## Question
difficulty: 中等
type: SINGLE_CHOICE
content: Java中用于表示一个类继承另一个类的关键字是哪个？
options:
- A. import
- B. extends
- C. package
- D. implements
answer: B
analysis: extends 用于类继承。

## Question
