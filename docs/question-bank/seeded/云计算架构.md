## Question
difficulty: 中等
type: SHORT_ANSWER
content: 请简述PaaS与SaaS的区别。
answer: PaaS提供应用开发和运行平台，SaaS直接提供可使用的软件服务
analysis: PaaS面向开发部署平台，SaaS面向最终软件能力。

## Question
difficulty: 中等
type: TRUE_FALSE
content: SaaS更偏向于向最终用户直接提供可使用的软件能力。
options:
- 正确
- 错误
answer: 正确
analysis: SaaS面向直接使用软件的用户，PaaS则更偏向开发和部署平台。

## Question
difficulty: 中等
type: FILL_BLANK
content: 如果企业需要直接管理操作系统与中间件，通常更接近哪类服务模式？
answer: IaaS
analysis: IaaS为用户提供基础设施层资源，用户仍需管理较多上层环境。
