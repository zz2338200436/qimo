## Question
difficulty: 中等
type: FILL_BLANK
content: 线性表的顺序存储结构通常使用什么来存放元素？
answer: 数组
analysis: 顺序表通常用一段连续存储空间保存元素。

## Question
difficulty: 中等
type: SHORT_ANSWER
content: 顺序表随机访问效率通常较高的主要原因是什么？
answer: 存储空间连续，可按下标直接定位
analysis: 连续存储支持通过地址偏移快速访问指定元素。

## Question
difficulty: 中等
type: TRUE_FALSE
content: 链表插入新节点时通常不需要整体移动大量元素。
options:
- 正确
- 错误
answer: 正确
analysis: 链表通过修改指针关系完成插入，避免了顺序表大规模搬移。
