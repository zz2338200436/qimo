## Question
difficulty: 中等
type: TRUE_FALSE
content: 容器相比传统虚拟机通常具有启动更快、镜像更轻量的特点。
options:
- 正确
- 错误
answer: 正确
analysis: 容器共享宿主机内核，通常比完整虚拟机更轻量。

## Question
difficulty: 中等
type: SINGLE_CHOICE
content: 容器与传统虚拟机相比，哪项说法更合理？
options:
- 容器必须独占一套完整客户机操作系统
- 容器通常共享宿主机内核，因此更轻量
- 容器不支持镜像分发
- 虚拟机不能做资源隔离
answer: B
analysis: 容器共享宿主机内核，因此通常启动更快、开销更小。
