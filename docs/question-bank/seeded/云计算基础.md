## Question
difficulty: 简单
type: SINGLE_CHOICE
content: 云计算的典型特征不包括哪一项？
options:
- 按需自助服务
- 资源池化
- 快速弹性伸缩
- 必须购买固定物理服务器
answer: D
analysis: 云计算强调按需使用和弹性资源，而不是固定购买物理服务器。

## Question
difficulty: 简单
type: TRUE_FALSE
content: IaaS主要向用户提供计算、存储、网络等基础设施资源。
options:
- 正确
- 错误
answer: 正确
analysis: IaaS是基础设施即服务。

## Question
difficulty: 中等
type: TRUE_FALSE
content: 按需自助服务是云计算的重要特征之一。
options:
- 正确
- 错误
answer: 正确
analysis: 用户可以按需申请资源而不必人工逐次介入。

## Question
difficulty: 中等
type: SHORT_ANSWER
content: 资源池化在云计算中意味着什么？
answer: 底层资源被统一管理并按需分配给多个租户
analysis: 资源池化强调共享基础设施并通过抽象层实现灵活调度。
