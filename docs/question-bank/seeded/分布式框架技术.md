## Question
difficulty: 中等
type: SINGLE_CHOICE
content: 微服务架构中，将系统拆分为多个自治服务的主要目的不包括哪一项？
options:
- 降低单体复杂度
- 支持独立部署
- 便于按业务边界扩展
- 保证所有服务共享同一个数据库表
answer: D
analysis: 微服务强调服务自治，不应强制所有服务共享同一张业务表。

## Question
difficulty: 中等
type: SHORT_ANSWER
content: 分布式系统中，服务调用链路追踪主要解决什么问题？
answer: 定位跨服务请求路径和性能瓶颈
analysis: 链路追踪通过traceId/spanId记录请求经过的服务和耗时。

## Question
difficulty: 中等
type: SHORT_ANSWER
content: 微服务拆分时，常见的边界划分依据是什么？
answer: 业务领域边界
analysis: 服务划分通常围绕业务能力和领域边界，而不是简单按技术层拆分。

options:

## Question
difficulty: 中等
type: MULTIPLE_CHOICE
content: 以下哪些属于微服务拆分应遵循的原则？
options:
- 按业务领域拆分
- 高内聚、低耦合
- 每个服务拥有独立数据库
- 所有服务使用相同的技术栈
answer: A,B,C
analysis: 微服务拆分应按业务、追求高内聚低耦合、数据独立，不要求统一技术栈。

## Question
difficulty: 中等
type: TRUE_FALSE
content: 在分布式系统中，网络分区（Network Partition）是不可避免的。
options:
- 正确
- 错误
answer: 正确
analysis: 根据CAP定理，网络分区在实际分布式系统中总会发生，P（分区容错性）几乎是必选项。

## Question
difficulty: 中等
type: TRUE_FALSE
content: 微服务架构中所有服务必须使用同一编程语言开发。
options:
- 正确
- 错误
answer: 错误
analysis: 微服务之间通过标准协议通信，各服务可使用不同语言和技术栈，这是微服务的一大优势。

## Question
difficulty: 中等
type: FILL_BLANK
content: 分布式链路追踪中，用于唯一标识一次完整请求调用链的ID通常称为______。
answer: TraceId
analysis: TraceId贯穿整个调用链路，配合SpanId可精确追踪每个服务节点的耗时和状态。

## Question
difficulty: 中等
type: FILL_BLANK
content: 微服务架构中实现服务间通信的两种主要模式是同步调用和______。
answer: 异步消息
analysis: 同步调用如REST/RPC，异步消息如Kafka/RabbitMQ，两者可组合使用。

## Question
difficulty: 困难
type: SHORT_ANSWER
content: 请简述分布式系统中"雪崩效应"及其常见应对策略。
answer: 熔断降级防止级联故障，限流保护服务，快速失败避免资源耗尽
analysis: 雪崩效应：一个服务不可用导致依赖方连锁崩溃。应对：熔断器(Circuit Breaker)、服务降级、限流、超时控制、线程隔离。
