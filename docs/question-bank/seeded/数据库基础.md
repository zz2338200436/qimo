## Question
difficulty: 简单
type: FILL_BLANK
content: 关系数据库中用于唯一标识一条记录的字段或字段组合称为什么？
answer: 主键
analysis: 主键用于唯一标识表中的一行数据。

## Question
difficulty: 简单
type: SINGLE_CHOICE
content: 数据库中的外键主要用于表达哪种关系？
options:
- 字段默认值
- 表与表之间的引用关系
- 索引排序方式
- 事务隔离级别
answer: B
analysis: 外键建立当前表字段到另一张表主键或唯一键的引用。

## Question
difficulty: 中等
type: SHORT_ANSWER
content: 主键字段的一个关键要求是什么？
answer: 取值唯一且不能为空
analysis: 主键需要唯一标识记录，因此必须唯一且非空。

## Question
difficulty: 中等
type: TRUE_FALSE
content: 关系模型中，外键的核心作用是维护表之间的参照完整性。
options:
- 正确
- 错误
answer: 正确
analysis: 外键通过引用另一表的主键或唯一键来建立和约束关系。
