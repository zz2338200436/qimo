## Question
difficulty: 困难
type: FILL_BLANK
content: 事务ACID特性中的I代表什么？
answer: 隔离性
analysis: ACID分别是原子性、一致性、隔离性、持久性。

## Question
difficulty: 困难
type: TRUE_FALSE
content: 脏读是指一个事务读取到了另一个事务尚未提交的数据。
options:
- 正确
- 错误
answer: 正确
analysis: 未提交读隔离级别下可能出现脏读。

## Question
difficulty: 困难
type: TRUE_FALSE
content: 事务的一致性强调事务执行前后数据应满足既定约束。
options:
- 正确
- 错误
answer: 正确
analysis: 一致性要求事务不会破坏业务规则和完整性约束。

## Question
difficulty: 困难
type: FILL_BLANK
content: 可重复读主要用来减少哪类并发现象？
answer: 不可重复读
analysis: 可重复读保证同一事务中多次读取同一记录结果一致。

## Question
difficulty: 困难
type: SINGLE_CHOICE
content: 下列哪项最能体现事务的原子性？
options:
- 一组操作要么全部成功要么全部失败回滚
- 多个事务可以随意看到彼此未提交数据
- 事务执行后自动创建索引
- 事务只能包含一条SQL
answer: A
analysis: 原子性强调事务是不可再分的最小执行单元。
