## Question
difficulty: 中等
type: SHORT_ANSWER
content: 请简述面向对象程序设计中封装的含义。
answer: 将数据和操作数据的方法封装在对象内部，并通过受控接口访问
analysis: 封装降低对象内部实现对外部调用者的暴露程度。

## Question
difficulty: 中等
type: FILL_BLANK
content: 接口与抽象类相比，更适合描述什么？
answer: 行为规范
analysis: 接口更强调对外能力约定，抽象类更适合抽取公共状态和基础实现。

## Question
difficulty: 中等
type: SINGLE_CHOICE
content: 下列哪项最能体现多态？
options:
- 子类不能重写父类方法
- 对象创建时必须使用Object类型
- 父类引用在运行时指向子类对象并调用重写方法
- 一个类只能有一个构造方法
answer: C
analysis: 多态的核心是统一接口下的不同实现，运行时调用具体子类的重写逻辑。

## Question
difficulty: 中等
type: SHORT_ANSWER
content: 请简述继承在面向对象设计中的主要作用。
answer: 复用和扩展已有类的属性与行为
analysis: 继承可以基于已有类构建更具体的子类，同时保留并扩展原有能力。
