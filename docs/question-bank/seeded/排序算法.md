## Question
difficulty: 中等
type: SINGLE_CHOICE
content: 在平均情况下，快速排序的时间复杂度通常是多少？
options:
- O(n)
- O(n log n)
- O(n^2)
- O(log n)
answer: B
analysis: 快速排序平均时间复杂度为O(n log n)，最坏情况下可能退化为O(n^2)。

## Question
difficulty: 中等
type: TRUE_FALSE
content: 冒泡排序在最坏情况下的时间复杂度是O(n^2)。
options:
- 正确
- 错误
answer: 正确
analysis: 冒泡排序和插入排序在最坏情况下都可能达到平方级复杂度。
