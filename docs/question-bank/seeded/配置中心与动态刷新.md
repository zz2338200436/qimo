## Question
difficulty: 中等
type: SHORT_ANSWER
content: 配置中心相比写死在本地配置文件中的主要优势是什么？
answer: 可以集中管理多环境配置并支持配置变更统一发布
analysis: 配置中心便于统一维护、审计和动态刷新配置。

## Question
difficulty: 中等
type: SHORT_ANSWER
content: 如果配置中心支持动态刷新，通常意味着什么？
answer: 部分配置变更后可在运行期生效
analysis: 动态刷新减少了改配置必须整体重启服务的成本。

## Question
difficulty: 中等
type: TRUE_FALSE
content: 配置中心的环境隔离有助于避免开发、测试、生产配置相互混用。
options:
- 正确
- 错误
answer: 正确
analysis: 环境隔离能降低误用配置带来的运行风险。

## Question
difficulty: 中等
type: SINGLE_CHOICE
content: 下列哪项不属于配置中心的核心功能？
options:
- 集中管理多环境配置
- 配置变更实时推送
- 配置版本管理与回滚
- 替代消息队列
answer: D
analysis: 配置中心处理配置管理，不替代消息队列（MQ）的功能。

## Question
difficulty: 中等
type: SINGLE_CHOICE
content: Spring Cloud Config支持使用以下哪种存储后端存放配置文件？
options:
- Redis
- Git仓库
- MongoDB
- Elasticsearch
answer: B
analysis: Spring Cloud Config天然支持Git作为配置存储后端，也支持本地文件系统和JDBC。

## Question
difficulty: 简单
type: TRUE_FALSE
content: 使用配置中心可以实现不重启服务即更新运行中的配置。
options:
- 正确
- 错误
answer: 正确
analysis: 通过Spring Cloud Bus + @RefreshScope或Nacos的配置监听机制可实现配置热更新。

## Question
difficulty: 中等
type: SHORT_ANSWER
content: 请简述配置管理中"环境隔离"的重要性和常见实现方式。
answer: 重要性：开发/测试/生产环境配置独立，防止错误配置影响生产。实现：按Profile区分(dev/test/prod)、按命名空间(Namespace)隔离、配置加密存储。
analysis: 环境隔离是配置管理的基本原则。常见方式：Spring Profile、Nacos命名空间、Apollo集群管理。
