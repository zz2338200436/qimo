## Question
difficulty: 中等
type: TRUE_FALSE
content: 服务注册中心通常保存服务实例的地址、端口和健康状态等信息。
options:
- 正确
- 错误
answer: 正确
analysis: 消费者可以从注册中心发现可用服务实例。

## Question
difficulty: 中等
type: SINGLE_CHOICE
content: 下列哪项更符合服务发现的作用？
options:
- 让调用方找到可用服务实例
- 编译Java源代码
- 替代数据库事务
- 生成前端页面样式
answer: A
analysis: 服务发现用于在运行时获取可调用的服务实例。

## Question
difficulty: 中等
type: SHORT_ANSWER
content: 服务实例注册到注册中心后，消费者通常通过什么信息完成调用定位？
answer: 服务名和实例元数据
analysis: 服务发现通常先按服务名查询，再结合实例地址、端口和状态进行调用。

## Question
difficulty: 中等
type: SINGLE_CHOICE
content: 注册中心中健康检查信息的主要价值是什么？
options:
- 统一编译Java代码
- 帮助剔除不可用实例，提升调用成功率
- 替代消息队列
- 直接生成前端页面
answer: B
analysis: 健康检查可用于发现故障实例并避免继续路由流量。

## Question
difficulty: 简单
type: SINGLE_CHOICE
content: 以下哪项属于常见的服务注册中心？
options:
- MySQL
- Redis
- Nacos
- Nginx
answer: C
analysis: Nacos是阿里巴巴开源的服务注册与配置中心。Consul和Eureka也是常见注册中心。

## Question
difficulty: 中等
type: SINGLE_CHOICE
content: Eureka服务注册中心中，默认的心跳检测间隔通常是？
options:
- 15秒
- 30秒
- 60秒
- 90秒
answer: B
analysis: Eureka客户端默认每30秒发送一次心跳，若90秒未收到心跳则剔除实例。

## Question
difficulty: 中等
type: MULTIPLE_CHOICE
content: 以下哪些属于服务注册中心的常见职责？
options:
- 服务实例注册
- 健康检查
- 服务发现
- 直接处理业务请求
answer: A,B,C
analysis: 注册中心负责注册、发现和健康监测，不处理业务请求。流量由调用方直连服务实例。

## Question
difficulty: 简单
type: TRUE_FALSE
content: 客户端负载均衡是指由服务调用方根据注册中心返回的实例列表自行选择实例。
options:
- 正确
- 错误
answer: 正确
analysis: 客户端负载均衡（如Ribbon/LoadBalancer）在调用方本地选择实例，无需经过代理。

## Question
difficulty: 困难
type: SHORT_ANSWER
content: 请解释服务注册中心中"服务级别协议（SLA）"的含义及常见指标。
answer: SLA是服务提供方与消费方间的质量约定，常见指标包括可用性(如99.9%)、响应时间(如P99<200ms)、错误率等
analysis: SLA（Service Level Agreement）用于量化服务质量，驱动服务治理策略（如限流、熔断阈值设定）。
