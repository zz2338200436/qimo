## Question
difficulty: 中等
type: TRUE_FALSE
content: 栈的基本操作特点是先进先出。
options:
- 正确
- 错误
answer: 错误
analysis: 栈是后进先出，队列才是先进先出。

## Question
difficulty: 中等
type: FILL_BLANK
content: 队列的典型操作特点是什么？
answer: 先进先出
analysis: 队列在队尾入队，在队头出队。

## Question
difficulty: 中等
type: FILL_BLANK
content: 栈最典型的操作原则是什么？
answer: 后进先出
analysis: 栈顶后入先出，是递归和函数调用的重要抽象。

## Question
difficulty: 中等
type: SHORT_ANSWER
content: 循环队列的一个常见目的是什么？
answer: 提高数组存储空间的复用率
analysis: 循环队列通过首尾回绕避免普通顺序队列前部空间浪费。
