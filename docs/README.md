# 文档导航索引

> 版本：v0.2
> 最后更新：2026-05-14
> 作者：架构组

本目录承载 `spring-cloud-migration` 规格说明的全部交付物文档。文档统一采用 Markdown 撰写，结构图使用 Mermaid / PlantUML 等文本化格式，便于版本化与评审。各篇文档会随迁移阶段推进而持续补全，请以"变更记录"表格为准跟踪版本演进。

## 维护约定

- `docs/` 目录下文档用于承载项目级说明，重点记录架构、迁移阶段、风险、回滚、部署与治理约束。
- `.kiro/specs/spring-cloud-migration/` 目录下的 `requirements.md / design.md / tasks.md` 用于承载规格化需求、设计与实施任务。
- 接口级实施状态、任务勾选进度、Gateway 切流范围以 `.kiro/specs/spring-cloud-migration/tasks.md` 为唯一真相来源；`docs/migration-plan.md` 只保留阶段、里程碑与风险判断。

## 文档列表

- [诊断报告](./diagnosis-report.md) — 记录现状治理阶段识别出的代码质量、安全、性能、可观测性等问题清单及改造建议。
- [目标架构](./architecture.md) — 描述 Spring Cloud 微服务化改造后的目标架构、组件选型与部署拓扑（含结构图）。
- [认证授权方案](./auth-design.md) — 定义跨服务的统一认证授权方案，包括 Token 设计、网关鉴权与多角色会话策略。
- [数据所有权矩阵](./data-ownership.md) — 明确各微服务负责的领域数据与数据库边界，禁止跨服务直连他方库表。
- [迁移计划](./migration-plan.md) — 给出三阶段迁移路径、依赖顺序、切流与回滚策略以及里程碑验收标准；不逐项维护接口级实施清单。
- [编码规范](./coding-guidelines.md) — 统一代码风格、分层约束、异常处理、日志与接口契约约定。
- [可观测性方案](./observability.md) — 规划日志、链路追踪、指标与告警体系，以及 TraceId 贯穿链路。
- [部署与运维手册](./deployment.md) — 描述基础设施、环境分层、发布流程、配置管理与故障处置 SOP。
